# EMAIL · Skills Registry

## Registered Skills

### Strategy & Planning

#### 1. `email.strategy`
Develop email marketing strategy — channel positioning, lifecycle mapping, campaign calendar, KPI framework.
- Input: business goals, audience segments, current metrics, product/offer mix
- Output: email strategy doc with lifecycle stages, campaign types, KPIs, tooling recommendations

#### 2. `email.calendar`
Design email campaign calendar — cadence planning, seasonal campaigns, trigger-based scheduling, promotional timing.
- Input: product launches, seasonal events, content pipeline, audience engagement data
- Output: 90-day email calendar with campaign dates, sequences, segments, goals

### Sequence & Campaign Design

#### 3. `email.sequence`
Design multi-step email sequences — welcome, onboarding, nurturing, re-engagement, post-purchase.
- Input: lifecycle stage, audience, goal, timeline, triggers
- Output: full sequence spec with steps, timing, triggers, fallback rules, success metric

#### 4. `email.drip`
Design drip campaigns — automated behavior-triggered email flows with branching logic.
- Input: trigger events (signup, download, cart abandon, etc.), audience segments, conversion goals
- Output: drip campaign map with triggers, conditions, branches, timing, content briefs

#### 5. `email.nurture`
Design lead nurture sequences — educational value sequences that build trust and move prospects through the funnel.
- Input: ICP, pain points, buying journey stage, content library, offer cadence
- Output: nurture sequence with content mapping, touch timing, escalation triggers, CTA progression

#### 6. `email.re-engagement`
Design re-engagement and win-back sequences — dormant subscriber revival, churn prevention, sunset policies.
- Input: inactive segment definition, churn data, win-back offers, sunset timeline
- Output: re-engagement campaign with escalation, offer strategy, sunset policy, success metrics

### Copy & Creative

#### 7. `email.copy-subject`
Write and optimize email subject lines — preview text optimization, emoji strategy, personalization, A/B variants.
- Input: campaign goal, audience segment, brand voice, length constraints, platform limits
- Output: subject line set with primary + A/B variants, preview text, emoji guidance, rationale

#### 8. `email.copy-body`
Write email body copy — persuasive, value-driven content with CTAs that convert.
- Input: value proposition, audience, sequence step, brand voice, desired action
- Output: email body copy with headline, body paragraphs, CTA buttons, PS note, personalization hooks

#### 9. `email.copy-cta`
Design email CTAs — button copy, placement, design, urgency tactics, click-through optimization.
- Input: conversion goal, audience, email design, device distribution, brand guidelines
- Output: CTA specs with copy variants, button design, placement, urgency tactics, a11y considerations

### Deliverability & Infrastructure

#### 10. `email.deliverability`
Optimize email deliverability — sender reputation, authentication (SPF/DKIM/DMARC), ISP relationships, blocklist recovery.
- Input: sending domain, current metrics (bounce, complaint, spam), provider, sending volume
- Output: deliverability audit with authentication status, reputation analysis, blocklist check, remediation roadmap

#### 11. `email.authentication`
Configure and audit email authentication — SPF record, DKIM signing, DMARC policy, BIMI, MTA-STS, TLS-RPT.
- Input: sending domain, current DNS records, provider requirements
- Output: authentication spec with record values, deployment order, monitoring setup, migration plan

#### 12. `email.warmup`
Plan email warmup — gradual volume ramp, engagement targeting, reputation building, seed list management.
- Input: new domain/IP, target sending volume, provider limits, timeline
- Output: warmup plan with daily volume schedule, engagement seeding, progress checkpoints, provider-specific guidance

#### 13. `email.list-hygiene`
Manage list hygiene — bounce handling, suppression lists, list decay, re-verification cadence, sunset policies.
- Input: list size, bounce rate, engagement metrics, industry benchmarks
- Output: list hygiene policy with bounce handling, suppression rules, re-verification cadence, sunset procedures

### Compliance & Legal

#### 14. `email.compliance-can-spam`
CAN-SPAM compliance review — unsubscribe mechanism, physical address, sender identification, subject accuracy, commercial disclosure.
- Input: email content, sender info, recipient location, mailing practices
- Output: CAN-SPAM compliance checklist with pass/fail per requirement, remediation steps

#### 15. `email.compliance-gdpr`
GDPR compliance for email marketing — consent records, data processing, right to erasure, privacy policy linkage.
- Input: recipient location (EU), data collection method, existing consent records
- Output: GDPR compliance checklist with consent audit, data flow mapping, erasure procedure, DPIA requirements

#### 16. `email.compliance-casl`
CASL compliance for Canadian email — express consent verification, implied consent rules, sender identification, unsubscribe mechanism.
- Input: recipient location (Canada), consent type, email content, business relationship
- Output: CASL compliance checklist with consent validation, content requirements, record-keeping, exceptions

### Analytics & Optimization

#### 17. `email.analytics`
Design email analytics framework — KPI selection, dashboard design, attribution modeling, cohort analysis.
- Input: campaign types, business goals, data sources, reporting frequency
- Output: analytics framework with KPIs, dashboard mockup, attribution model, cohort definitions, reporting schedule

#### 18. `email.ab-testing`
Design email A/B tests — test hypothesis, variant design, sample size calculation, statistical significance.
- Input: current performance, improvement hypothesis, list size, sending frequency
- Output: A/B test plan with hypothesis, variants, sample size, duration, success criteria, analysis framework

#### 19. `email.optimization`
Optimize email performance — send time optimization, frequency tuning, engagement analysis, revenue per email improvement.
- Input: campaign performance data, historical metrics, audience engagement patterns
- Output: optimization recommendations with timing, frequency, segmentation, content, and technical improvements

### Technical & Infrastructure

#### 20. `email.api`
Design email API integrations — Resend API, webhook handling, bounce/complaint processing, event tracking.
- Input: sending provider, integration type (transactional/marketing), volume, event needs
- Output: integration spec with API endpoints, webhook handlers, event schema, error handling, rate limiting

#### 21. `email.template`
Design email HTML templates — responsive design, email client compatibility, dark mode, accessibility, tracking pixels.
- Input: brand guidelines, device distribution, email clients supported, tracking requirements
- Output: email template with HTML/CSS, responsive breakpoints, dark mode styles, accessibility markup, tracking integration

#### 22. `email.personalization`
Design email personalization strategy — dynamic content, merge tags, behavioral triggers, predictive personalization.
- Input: audience data fields, behavioral data, personalization goals, privacy constraints
- Output: personalization spec with dynamic content rules, merge fields, trigger conditions, fallback defaults

#### 23. `email.inbound`
Design inbound email handling — reply management, auto-responders, ticket creation, sentiment routing.
- Input: incoming volume, reply types (inquiries/complaints/orders), team capacity, integration needs
- Output: inbound email system spec with routing rules, auto-response templates, escalation paths, integration mappings

### Provider & Platform

#### 24. `email.provider-resend`
Resend-specific configuration — API key management, domain setup, sending quotas, webhook wiring, bounce handling.
- Input: Resend account details, domain, sending volume, event requirements
- Output: Resend configuration guide with domain setup, API integration, quota management, webhook handling, template setup

#### 25. `email.provider-listmonk`
ListMonk-specific configuration — self-hosted setup, campaign management, subscriber management, template system, API integration.
- Input: ListMonk instance, domain, sending volume, subscriber list requirements
- Output: ListMonk configuration guide with installation, campaign setup, subscriber import, template system, API wiring
