# NWS Severity Reference

## Alert Categories
- **Warnings** — Imminent threat, take action now. Highest priority.
- **Watches** — Conditions favorable, prepare. Medium priority.
- **Advisories** — Less severe, be aware. Lower priority.
- **Statements** — Follow-up information. Informational only.

## Severity Mapping
| NWS Event | Severity | Typical Urgency |
|---|---|---|
| Tornado Warning | Extreme | Immediate |
| Severe Thunderstorm Warning | Severe | Expected |
| Flash Flood Warning | Severe | Immediate |
| Hurricane Warning | Extreme | Expected |
| Winter Storm Warning | Moderate | Expected |
| Heat Advisory | Minor | Expected |
