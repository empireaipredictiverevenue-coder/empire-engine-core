📖 Webhook Integration Guide

Endpoint

POST https://empire-ai.co.uk/api/v1/claim-settled

Authentication

Include your API key in the Authorization header:

Authorization: Bearer cem_<your-api-key>

Request Format

{ "dispatch_id": "uuid", // required — Empire AI dispatch UUID "claim_amount": 125000.00, // required — settlement amount in USD "claim_id": "CARRIER-001", // optional — your internal claim ref "settled_at": "2026-06-19T14:00:00+00:00", // optional "loss_description": "Hail damage to roof" // optional }

Response

{ "ok": true, "fee_event_id": "uuid", "fee_amount": 3750.00, "claim_amount": 125000.00, "fee_percent": 0.03, "dispatch_id": "uuid", "claim_id": "your-claim-ref" }

Fee Model

Empire AI collects 3% of the settled claim amount. The fee is calculated and stored when the webhook is received. No payment is collected at webhook time — the fee is tracked in our ledger and invoiced periodically.

Rate Limits

  • Maximum claim amount: $100,000,000
  • Minimum claim amount: $0.01
  • No rate limit on requests (we expect 1-10 per day per carrier)

Idempotency

If the same dispatch_id is submitted twice, the second request will return already_settled: true and no duplicate fee will be created. This is safe for network retries.
